Numeric Date Format

Starting with Odoo 19, date fields show a short style such as “Nov 4” and hide the year. This module shows the full date in your language's format, such as 11/04/2026, in every view, as Odoo 16, 17 and 18 did.

Key features

📅

Full date, always

The year is always shown, so 04/11/2026 and 04/11/2025 never look alike.

🌍

Follows your language

Uses the Date Format and Time Format set in Settings › Languages, for each user.

🧩

Works everywhere

Form, list and kanban views and grouped lists, in Sales, Purchase, Inventory and every other app.

⚡

Install and done

No configuration and no new fields. It only depends on web.

🛡️

Display only

Nothing is written to the database. Uninstall it and Odoo's standard display returns.

📏

No cut-off dates

Placeholders and list column widths are sized for the longer numeric format.

Choosing the format

Go to Settings › Translations › Languages, open your language and set Date Format (for example %d/%m/%Y or %m/%d/%Y) and Time Format (%H:%M:%S shows seconds, %H:%M hides them). Dates follow it immediately.

Settings › Languages: Date Format and Time Format

Good to know

  • After installing, hard-refresh the browser (Ctrl+Shift+R) so it loads the new assets.
  • Chatter message times, Gantt headers and spreadsheets have their own date display and are not changed.
  • Fields that already use options="{'numeric': True}" keep working as before.
